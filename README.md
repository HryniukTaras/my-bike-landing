# 🚲 MyBike Landing Page

Welcome to the MyBike landing page project! The website is designed to provide users with an overview of bike features, company information, and ways to get in touch.

# Overview

The project is a landing page for a bike company. The page is responsive and suitable for different screen sizes. The design is based on the provided mockup and is visually appealing. The code is organized and follows best practices. SCSS and BEM were used for styling.

# Technologies Used

- HTML
- CSS (SCSS for styling)

# Usage

The landing page includes various sections that users can navigate through:

- Move: This section provides an overview of the bike features.
- Compare bikes: This section allows users to compare different bikes.
- Details: This section provides more detailed information about the bike features.
- Contact us: Includes contact information and links to social media.

To use the project, follow these steps:

1. Clone the repository
2. Run `npm install` to install the dependencies
3. Run `npm start` to start the development server
4. Open the website in the browser at `http://localhost:3000`
